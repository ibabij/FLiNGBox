## ✨ 功能特点

- ⬇️ **多版本下载与自动就绪**：支持自动在线更新版与历史离线版本下载
- 🎮 **本地修改器库**：卡片式本地管理，支持一键极速启动
- 📖 **修改功能与详情预览**：完整展示热键列表、特别说明及游戏背景原画预览。


---

## 🚀 快速开始

### 运行环境
- Node.js >= 18
- Windows 10 / 11

### 安装与运行

```bash
# 1. 安装依赖
npm install

# 2. 启动客户端
npm start

# 3. 打包生成安装包 (可选)
npm run build
```
