无需配置任何环境，直接下载打包好的单文件绿色便携版：

1. 前往 **[👉 GitHub Releases 页面](https://github.com/ibabij/FLiNGBox/releases/latest)** 下载最新版本的 **`FLiNG-Box-v*.exe`**。

## ✨ 功能特点

- ⬇️ **一键下载**：一键下载风灵月影官方修改器资源
- 📦 **支持历史版本选择**：完整提供最新版与历史不同版本的修改器下载列表，自由按需选择
- 🎮 **本地修改器库**：卡片式本地管理，支持一键极速启动修改器，快速定位文件目录
- 📖 **修改功能与详情预览**：完整展示快捷键列表、特别说明及游戏背景原画预览
- 🖼️ **图片本地持久化缓存**：自动缓存封面与原画到本地磁盘，弱网/离线秒开，支持在设置中一键清理
- 🔍 **游戏即时搜索**：支持快速搜索海量风灵月影修改器，轻松查找目标游戏

## 🛠️ 源码开发与运行

如果你需要自行二次开发或从源码运行：

### 运行环境
- Node.js >= 18
- Windows 10 / 11

### 安装与运行

```bash
# 1. 克隆仓库
git clone https://github.com/ibabij/FLiNGBox.git

# 2. 安装依赖
npm install

# 3. 启动开发模式
npm start

# 4. 打包生成单文件绿色版 (.exe)
npm run build:win
```
